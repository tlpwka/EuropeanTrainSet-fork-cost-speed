# European Train Set fork
 **European Train Set fork** is an OpenTTD NewGRF that adds European railway vehicles to the game.\

 ## Development
Major overhaul adding configurable economics and a broad speed rebalance across the French high-speed roster.

    Adjustable costs: New purchase and running cost multipliers (÷16 to ×16, default ×1) applied globally via cost_factor/running_cost_factor, replacing fixed values on most trains and wagons.
    Speed increases: Significant top-speed bumps for AGV (390), ICE 4 (365), TGV M (502), and others; several units now use year-dependent adaptive speed callbacks.
    Cargo flexibility: Passenger vehicles can now be refitted to carry mail and valuables in addition to passengers.
    Consist changes: TGV M can attach postal wagons; Eurostar E320 supports double-heading with itself.
    Spec corrections: Introduction dates fixed for AGV, Eurostar E320, TGV POS, and others.
